📐 Maths – Chapterwise Formulas

➤ – Sets
  • n(A ∪ B) = n(A) + n(B) – n(A ∩ B)
  • n(A ∩ B) = n(A) + n(B) - n(A ∪ B)
  • A ⋂ (B ⋂ C) = (A ⋂ B) ⋂ C
  • A ∪ (B ∪ C) = (A ∪ B) ∪ C
  • A ⋂ Ø = Ø
  • U ⋂ A = A
  • A ∪ Ø = A
  • U ∪ A = U
  • A Δ B = (A-B) ∪ (B-A)
  • n(A’) = n(U) – n(A)
  • n((A∪B)’) = n(U) + n(A⋂B) – n(A) – n(B)
  • n(A∪B∪C) = n(A)+n(B)+n(C) - n(A⋂B) - n(A⋂C) - n(B⋂C) + n(A⋂B⋂C)
➤ – Relation & Function
  • A × B = { (a,b) : a ∈ A, b ∈ B }
  • A × B ≠ B × A
  • A × A × A = {(a,b,c) : a,b,c ∈ A}
  • (f+g)(x) = f(x) + g(x), x ∈ X
  • (f-g)(x) = f(x) - g(x), x ∈ X
➤ – Trigonometry
  • sin²θ + cos²θ = 1
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = csc²θ
  • sin(A+B) = sinA cosB + cosA sinB
  • sin(A-B) = sinA cosB - cosA sinB
  • cos(A+B) = cosA cosB - sinA sinB
  • cos(A-B) = cosA cosB + sinA sinB
  • tan(A+B) = (tanA + tanB)/(1 - tanA tanB)
  • tan(A-B) = (tanA - tanB)/(1 + tanA tanB)
  • sinA + sinB = 2 sin((A+B)/2) cos((A-B)/2)
  • sin(2θ) = 2 sinθ cosθ = 2 tanθ / (1 + tan²θ)
  • cos(2θ) = cos²θ - sin²θ = 1 - 2 sin²θ = 2 cos²θ - 1 = (1 - tan²θ)/(1 + tan²θ)
  • tan(2θ) = 2 tanθ / (1 - tan²θ)
➤ – Sequence & Series
  • aₙ = a + (n-1)d
  • Sₙ = n/2(2a + (n-1)d) or Sₙ = n/2(a + aₙ)
  • aₙ = a·rⁿ⁻¹
  • Sₙ = a(1 - rⁿ)/(1 - r)
  • S∞ = a / (1 - r), when |r| < 1
➤ – P & C
  • ⁿCᵣ = ⁿCₙ₋ᵣ
  • nCᵣ = n! / (r!(n-r)!) = nPᵣ / r!
  • nCᵣ + nCᵣ₋₁ = (n+1)Cᵣ
  • nCᵣ₋₁ - (n-1)Cᵣ₋₁ = (n-r+1)·nCᵣ₋₁
➤ – Binomial Theorem
  • (a+b)ⁿ = nC₀aⁿ + nC₁aⁿ⁻¹b + … + nCᵣaⁿ⁻ʳbʳ + … + nCₙbⁿ
  • nCᵣ × r! = nPᵣ
  • Tᵣ₊₁ = nCᵣ aⁿ⁻ʳ bʳ
  • If n is even: Middle term = (n/2 +1)th term
  • If n is odd: Two middle terms = (n+1)/2th and (n+3)/2th
➤ – Straight line
  • Average Velocity: vavg = Δx / Δt
  • Instantaneous Velocity: v = dx / dt
  • Average Acceleration: aavg = Δv / Δt
  • Instantaneous Acceleration: a = dv / dt = d²x / dt²
  • v = u + a t
  • s = u t + ½ a t²
  • v² = u² + 2 a s
  • Upward motion: v = u - g t
  • Upward motion: s = u t - ½ g t²
  • Upward motion: v² = u² - 2 g s
  • Maximum height: h = u² / (2 g)
  • Time of flight: T = 2 u sinθ / g
  • Range: R = u² sin(2θ) / g
  • Maximum height: H = u² sin²θ / (2 g)

🔭 Physics – Formulas

➤ – Motion in Straight Line
  • Average Velocity: →vavg = Δ→x / Δt
  • Instantaneous Velocity: →v = d→x / dt
  • Average Acceleration: a⃗avg = Δv⃗ / Δt
  • Instantaneous Acceleration: a⃗ = dv⃗ / dt = d²x⃗ / dt²
  • v = u + at
  • s = ut + ½ a t²
  • v² = u² + 2 a s
  • v = u - g t (upward motion)
  • s = ut - ½ g t² (upward motion)
  • v² = u² - 2 g s (upward motion)
  • h = u² / (2g) (maximum height)
  • T = 2u sinθ / g (time of flight)
  • R = u² sin(2θ) / g (range)
  • H = u² sin²θ / (2g) (maximum height)
➤ – Newton's Laws of Motion
  • F = m a
  • FAB = −FBA (Newton’s Third Law)
  • Weight: W = m g
  • Normal Force: N = mg cosθ (on inclined plane)
  • Friction: fk = μk N, fs ≤ μs N
  • Net Force on System: Fext = Σ mi ai
  • Centripetal Force: Fc = m v² / r
  • Centripetal Acceleration: ac = v² / r
  • Velocity in Circular Motion: v = ω r
  • Impulse: J = F Δt
  • Momentum: p = m v
  • Impulse-Momentum Theorem: J = Δp
  • Conservation of Momentum: Σpinitial = Σpfinal
  • Collision (Elastic): m₁u₁ + m₂u₂ = m₁v₁ + m₂v₂
  • Collision (Inelastic): m₁u₁ + m₂u₂ = (m₁ + m₂) v
➤ – Work, Power, Energy
  • Work: W = →F · →S
  • Infinitesimal Work: dW = →F · d→S
  • Kinetic Energy: K = P² / (2 m), P = √(2 m K)
  • Potential Work: ∫r∞ →F · d→r = -W
  • Conservative Work: WC = -ΔU
  • Non-conservative Work + Potential Work: WNC + WPS = ΔK + ΔU
  • Total Work: WNC + WPS = ΔE
  • Power: P = →F · →v
➤ – COM & Rotational Motion
  • Angular Momentum: M→ = m r→
  • Center of Mass: r̅cm = (m₁ r̅₁ + m₂ r̅₂ + ... + mₙ r̅ₙ) / Σ mi
  • Angular Velocity: ωavg = Δθ / Δt, ω = dθ / dt
  • Angular Acceleration: αavg = Δω / Δt, α = dω / dt
  • Torque: τ→ = r→ × F→, τ = r F sin θ
  • Power in Rotation: P = τ ω
  • Work in Rotation: W = τ θ
  • Moment of Inertia: I = Σ mi ri²
  • Rotational Kinetic Energy: KE = ½ I ω²
  • Angular Momentum: L = I ω
  • Torque and Angular Momentum: τ = dL / dt

⚗️ Chemistry – Formulas

➤ – Mole Concept
  • Number of moles : n = Given mass (g) / Molar mass (g/mol)
  • No. of particles = Mol × 6.022×10²³
  • Moles from particles: n = Number of particles / (6.022 × 1023)
  • Volume of gas at STP: V = n × 22.4 L
  • Moles from volume: n = Volume (L) / 22.4
  • Determining n: n = Molar mass / Empirical formula mass
  • % Element = [(Mass of element in 1 mole) / (Molar mass)] × 100
  • Molality: m = w(g) × 1000 / (M × V(mL))
  • N = (Mass of solute × n-factor) / (Equivalent weight × Volume in L)
  • Molality (m) = moles of solute / mass of solvent (in kg)
➤ – Atomic Structure
  • E = hv
  • ν = c / λ
  • ν̅ = 1 / λ
  • E = hν = hc / λ
  • ν̅ = RH(1/n12 − 1/n22)
  • ν = (E2 − E1) / h
  • En = −2.18 × 10−18 (Z2 / n2) J
  • r = 52.9 × (n2 / Z) pm
  • λ = h / (m v) = h / p
➤ – Chemical Bonding & Molecular Structure
  • Type of d orbital involved: sp3d2 → dz2
  • sp3d2 → 2x − y, dz2
  • sp3d3 → 2x − y, dz2, dxy
  • dsp2 → dx2 − y2
  • Bond order (b.o.) = ½ (Nb − Na)
  • FC = Valence electrons − Non-bonding electrons − ½ × Bonding electrons
  • μ = q × d
➤ – Equilibrium
  • Kc = ([C]c[D]d) / ([A]a[B]b)
  • Kp = (PC)c(PD)d / ((PA)a(PB)b)
  • Kp = Kc(RT)Δn
  • Kw = [H+][OH−] = 1.0 × 10−14 (at 25°C)
  • Weak Acid (HA) Equilibrium: Ka = [H+][A−] / [HA], [H+] = √(KaCa)
  • Weak Base (B) Equilibrium: Kb = [BH+][OH−] / [B], [OH−] = √(KbCb)
  • Relationship: Ka × Kb = Kw
  • Henderson-Hasselbalch Equation: pH = pKa + log([A−] / [HA]), pOH = pKb + log([Salt] / [Base])
  • Solubility Product (Ksp): Ksp = S2 (S = solubility)
  • Degree of dissociation (α):
  • For A2 ⇌ 2A: Kp = 4α2P / (1 − α2)
  • For AB ⇌ A + B: Kp = α2P / (1 − α)
➤ – Thermodynamics
  • 1. First Law of Thermodynamics: ΔU = q + W
  • 2. Work for expansion/compression of gas (PV work): W = -P ΔV
  • 3. Enthalpy: H = U + PV, ΔH = ΔU + P ΔV
  • 4. Heat capacities: C_v = (∂U/∂T)_V, C_p = (∂H/∂T)_P, C_p - C_v = R (ideal gas)
  • 5. Gibbs free energy: ΔG = ΔH - TΔS
  • 6. Helmholtz free energy: A = U - TS, ΔA = ΔU - TΔS
  • 7. Relation between ΔG° & K: ΔG° = -RT ln K, K = e^(-ΔG° / RT)
  • 8. Gibbs free energy at non-standard conditions: ΔG = ΔG° + RT ln Q
  • 9. Van’t Hoff equation: ln(K₂ / K₁) = (ΔH° / R) (1/T₁ - 1/T₂)
  • 10. Entropy change of reaction: ΔS = (ΔH - ΔG)/T
  • 11. At equilibrium: ΔG = 0, Q = K
  • 12. Effect of temperature on K: Exothermic (ΔH° < 0) → K decreases with T↑, Endothermic (ΔH° > 0) → K increases with T↑
  • 13. Maximum work: W_max = -ΔG
  • 14. Relation between ΔH, ΔU, and Δn_gas (ideal gas): ΔH = ΔU + Δn_gas RT
  • 15. Clapeyron equation (phase change): dP/dT = ΔH_vap / (T ΔV)
  • 16. Boltzmann relation (statistical entropy): S = k_B ln Ω
